Lumiere Skin — Theme Documentation

Theme setup and configuration guide

Welcome to Lumiere Skin. This guide explains how to install the theme, customize its appearance, and configure common storefront features in Shopify.

1. Install the theme

  1. In your Shopify admin, go to Online Store → Themes.
  2. In the Theme library area, choose Add theme → Upload zip file.
  3. Select the Lumiere Skin theme ZIP and upload it.
  4. Preview the theme before publishing. Publish only after checking your storefront and settings.

2. Customize the storefront

  1. Go to Online Store → Themes and click Customize for Lumiere Skin.
  2. Use the page selector to choose the home page, product pages, collection pages, or other available templates.
  3. Select a section or block to edit its content, images, layout, and available settings.
  4. Use the theme settings panel for global colors, typography, and other site-wide options where available.
  5. Click Save after making changes.

3. Products and variants

Add and maintain products, product images, prices, inventory, and variants in Shopify admin → Products. If a product has options such as size or color, configure those options on the product itself. Preview each product page to verify that its options and purchase controls work as expected.

4. Collections and navigation

Create collections under Products → Collections. Manage storefront menus under Content → Menus (the exact menu label may vary by Shopify admin version). Assign the appropriate menus in the theme editor where menu settings are provided.

5. Search, cart, and checkout

Use Shopify's built-in product search and cart features. Test search results, add-to-cart behavior, variant selection, and the checkout handoff in the theme preview. Payment methods, shipping rates, taxes, and checkout policies are configured in Shopify admin, not solely in the theme.

6. Images and content

Use clear, high-quality product and banner images sized appropriately for their intended sections. Add descriptive alt text to meaningful images where the editor provides an alt-text field. Review text on mobile and desktop after replacing demo content.

7. Languages and markets

Configure available languages and market settings in Shopify admin. Where language or country selectors are available in the theme, choose the relevant options in the theme editor and test them in the storefront preview.

8. Troubleshooting

  • Changes are not visible: confirm you edited the intended theme and template, then save and refresh the preview.
  • Product options are missing: verify that the product has variants/options configured in Shopify admin.
  • Images appear cropped: review the section's image-fit or image-ratio settings, if available, and use images with suitable proportions.
  • App features do not appear: check the app's setup instructions and enable its app embed or app block if required.
  • Storefront behavior differs from preview: test the published theme, apps, and store settings; some behavior depends on Shopify configuration or installed apps.

9. Updates and backups

Before replacing or updating a theme, duplicate the current theme from Online Store → Themes so you have a backup. Recheck customizations and app integrations after any update.
